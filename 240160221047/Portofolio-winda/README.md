Tugas ini merupakan proyek website portofolio pribadi yang responsif, dibuat untuk memenuhi penilaian Ujian Tengah Semester (UTS) pada program studi Sistem Informasi semester 4. Website ini menampilkan profil akademis, kompetensi teknis, serta galeri proyek hasil praktikum perkuliahan.

## 🚀 Fitur Utama Website
* Hero & About Section: Menampilkan ringkasan profil personal dan tautan media sosial aktif (GitHub & Instagram).
* Technical Skills Bar:Representasi visual tingkat keahlian dalam pemrograman web dan pengelolaan basis data.
* Interactive Portfolio Grid: Galeri responsif yang menampilkan 6 proyek praktikum akademis menggunakan framework CSS Tailwind.
* Dark / Light Mode Toggle: Fitur interaktif (ikon bulan/matahari) yang memungkinkan pengunjung mengubah tema warna tampilan website demi kenyamanan visual.

---

## 📁 Daftar Proyek yang Ditampilkan
Berikut adalah 6 proyek akademis yang didokumentasikan dalam portofolio ini:
1. Basis Data Koperasi Digital: Perancangan struktur tabel relasional (`dbkoperasi`) dan pengelolaan query transaksi melalui phpMyAdmin.
2. Aplikasi SITOKO v1.0:Pengembangan modul halaman login administrator berbasis web dengan validasi autentikasi.
3. Sistem Kategori Mahasiswa (PBO):Implementasi konsep Polimorfisme untuk kalkulasi biaya kuliah per semester secara dinamis.
4. Manajemen Data Mahasiswa (PBO):Penerapan struktur Pewarisan (Inheritance) objek untuk mengelola daftar identitas akademik.
5. Ekstraksi Data Akademik (PBO): Pemanfaatan fungsi Enkapsulasi objek untuk mengamankan luaran (output) string data profil.
6. Proyek Media Informasi Digital:Perancangan aset visual kreatif berupa poster publikasi film "Watch In Silence" untuk kebutuhan branding organisasi.

---

## 🛠️ Teknologi yang Digunakan
* HTML5:Untuk menyusun struktur elemen konten pada halaman website.
* Tailwind CSS: Framework CSS untuk merancang tata letak (grid/flexbox) dan desain antarmuka yang responsif.
* JavaScript (Vanilla JS): Untuk memproses logika interaktif pada fitur penggantian tema (Dark Mode).
* Font Awesome v6: Library ikon eksternal untuk simbol media sosial dan navigasi tema.

---

## ⚙️ Cara Menjalankan Proyek Secara Lokal
1. Clone repository ini ke komputer lokal kamu.
2. Pastikan struktur folder gambar proyek sudah berada di lokasi `assets/images/Projects/`.
3. Buka file `index.html` menggunakan ekstensi **Live Server** di VS Code.
4. Akses halaman website melalui browser di alamat local host (`127.0.0.1:5500`).
